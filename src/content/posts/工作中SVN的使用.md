### 一、svn是什么？

-   集中式版本控制（Centralized VCS）。
    
-   所有历史版本集中存放在一台服务器，本地只保留当前工作副本。
    
-   核心概念：
    
    ```
    中央仓库：SVN 采用客户端-服务器模式。所有文件的历史版本都集中存储在一个中央服务器上。
    工作副本：开发者从中央服务器“检出”一份文件到自己的本地电脑，这份本地的文件就是工作副本。
    版本记录：SVN 会记录每一次文件提交，包括：谁、在什么时候、修改了哪些内容、以及为什么修改。每个版本都有一个唯一的版本号。
    提交与更新：
    提交：当你修改完本地代码后，通过“提交”操作将变更同步到中央服务器，从而创建一个新的版本。
    更新：通过“更新”操作，将本地工作副本与中央服务器的最新版本同步，获取其他同事的修改。
    ```
    

### 二、有了git，为啥还需要svn?

1.  **历史原因**：大量现存的老项目跑在 SVN 上，迁移成本和风险高。
2.  **场景需求**：对于需要**严格目录级权限控制**和**频繁处理大型二进制文件**（如游戏美术资源）的团队，SVN 的方案可能更简单、更稳定。
3.  **团队习惯**：对于非技术背景成员较多或团队习惯已定的情况，SVN 的统一、简单的工作流更容易管理和维护。

**结论就是：工具没有绝对的好坏，只有是否适合当前的团队和项目。** Git 在绝大多数软件开发场景下是更优的选择，但 SVN 在它的特定领域内，依然是一个可靠、甚至是更合适的选择。

### 三、svn的安装

svn是分为服务端和客户端的。对于我们使用者来说只用安装svn的客户端就行。就像git一样我们本地也是需要安装git的客户端，而服务端比如gitlab是不需要我们安装的。svn客户端的安装很简单，除了下图需要单独设置一下，其他的只要一直点击下一步即可！只有安装的时候选择下面这个 Command Line Client Tools 的时候，你的安装目录的bin目录下面才有svn.exe文件。这样，后续，在idea中集成svn的时候才可以选择它。

#### 6、分支操作

​ 正常情况需要进行分支操作的时候，我们需要建立如下三个目录：

| 目录名 | 用途 | 优点 |
| --- | --- | --- |
| trunk | 主开发线，存放最新的稳定代码 | 便于集中开发、持续集成 |
| branches | 用于并行开发、功能分支、修复分支等 | 支持多人协作、功能隔离、风险控制 |
| tags | 用于标记发布版本（如 v1.0、v2.0），通常只读，不修改 | 便于版本回溯、发布管理、归档 |

##### 6.1 新建分支

基于主干新建分支的时候，右击主干分支，按下图选择新建分支。

![新建分支](/uploads/images/2026-03-26/fb9140c1-b7af-4397-a6f3-23b64dd88bc7.png)

进入如下界面，填写对应信息，新建分支

![新建分支-详情](/uploads/images/2026-03-26/a04fe030-c11c-4428-8684-644bf9c56810.png)

需要注意的是，新建完分支之后，需要在update一下，本地对应目录才会有对应分支代码。

##### 6.2 合并分支

将分支内容合并到主干（branch => trunk），按如下步骤进行合并：

-   右击主干目录，点击 **Merge** 进行合并

![合并1](/uploads/images/2026-03-26/d92756af-4680-476b-8f3e-87ad8d3f5fe2.png)

-   进入如下界面直接点击下一步即可

![合并2](/uploads/images/2026-03-26/a5178630-f0d0-4d2a-b43a-102cf86a93c9.png)

-   进入如下界面，填写对应合并信息后，点击Next

![合并3](/uploads/images/2026-03-26/9150ef05-8345-4d6f-a856-cab0e6e79c6a.png)

-   一般按照默认就好 先点击 **Test merge** ，进行合并测试，合并测试没问题，再点击 **Merge** 合并

![合并4](/uploads/images/2026-03-26/1bb09968-71ff-4bbc-b586-0e56f22b5a3f.png)

需要注意的是，合并仅仅是合并到本地文件夹目录，所以合并完成后，记得要Commit提交到SVN。

![合并5](/uploads/images/2026-03-26/3853fcda-b926-4f80-81ca-770b0801e5e7.png)
